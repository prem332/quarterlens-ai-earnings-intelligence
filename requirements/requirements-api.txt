# Runtime dependencies for the deployed API container ONLY.

# requirements.txt remains the full set and is what CI and local development
# install -- it additionally covers the evaluation suite and the test runner.
# This file is what the Dockerfile installs, so the image does not ship
# packages the running service never imports.
#
# Excluded from here, with the reason each is safe to omit:
#   mlflow          only observability/mlflow_tracking.py imports it, and
#                   nothing the container runs imports that module. Verified by
#                   importing api.main + both model warm-ups + the CrewAI path
#                   and checking sys.modules. Removing it also drops pandas,
#                   pyarrow, matplotlib, sqlalchemy, alembic and flask, which
#                   in this dependency set are pulled in by mlflow alone --
#                   ~232 MB together.
#   beautifulsoup4  used only by data_pipeline's SEC download/parse scripts
#                   (document_parser, edgar_downloader, financials_fetcher,
#                   transcript_fetcher). Those are offline ingestion tools and
#                   are never executed in the container; the only data_pipeline
#                   import at runtime is chunking.sentences, via sentiment_agent,
#                   which does not pull it.
#   pytest          test runner, CI only. ~2.4 MB.
#   pytest-asyncio
#
# Deliberately KEPT even though a naive import scan flags them as unused --
# each is imported lazily and would break at request time:
#   uvicorn                 the container's CMD, invoked as a binary
#   reportlab, python-docx  imported inside the PDF/DOCX export handlers
#   arize-phoenix-otel      imported inside setup_phoenix()
#   openinference-*         imported inside the instrumentor helpers
#
# scipy and scikit-learn are NOT listed here and must not be removed: they are
# required by sentence-transformers, so they ship regardless of mlflow.
